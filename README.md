# Field Call & Conveyance Tracker PWA

A high-performance Progressive Web Application (PWA) designed to manage, track, and optimize school technical support field visits, ticket resolution workflows, and travel conveyance calculations.

## Key Capabilities
- **Interactive Field Call Grid**: Fast filtering, searching, and status tracking for hardware, networking, and software support calls.
- **Executive Dashboard**: Real-time KPI summaries, status distribution charts, and block-level completion metrics.
- **Smart Route Planner & Conveyance Engine**: Multi-stop route sequence calculation with automated distance measurement and conveyance claims.
- **Automated Reporting**: Instant 1-click WhatsApp daily executive summaries, individual ticket sharing, and Excel export.
- **Offline PWA Architecture**: Operates offline via Service Workers and LocalStorage persistence with zero server latency.
- **Theme Support**: Modern glassmorphic interface with light and dark mode support.

## Getting Started
Open `index.html` in any modern web browser or deploy directly to static hosting platforms like Cloudflare Pages or Vercel.
